# JENIOS — Template institucional de confirmação de conta (Supabase Auth)

Assunto sugerido: **JENIOS | Confirme sua conta**

Aplicação no Supabase hospedado:
1. Authentication → Email Templates.
2. Abra o template de confirmação de cadastro.
3. Substitua somente o HTML pelo conteúdo de `supabase/templates/jenios-confirmation.html`.
4. Preserve `{{ .ConfirmationURL }}` exatamente como está.
5. Não altere SMTP, domínio ou remetente durante esta troca visual.
6. Faça um cadastro de teste depois da publicação do template.
