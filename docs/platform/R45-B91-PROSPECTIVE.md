# B91 — Registro prospectivo local auditável apenas para pesquisa

Os registros criados pelo B89 são séries armazenadas no navegador. Um navegador não fornece carimbo temporal independente nem comprova que dados antigos não foram editados.
B91 audita ordem de timestamps, dupla data (último candle versus captura), dados futuros, duplicatas, atrasos e lacunas entre observações humanas.
A saída separa três afirmações: elegível para revisão educativa, fonte externa autenticada e desempenho do robô certificado. Apenas a primeira pode ser verdadeira sob estes requisitos; as demais continuam falsas.
Próxima exigência: servidor testemunhando capturas novas, provas de integridade fora da posse do cliente e comparação cega com o núcleo original.
Sem migração, ordens, pagamentos ou alteração no código original dos robôs. Não representa estatística de rentabilidade.
