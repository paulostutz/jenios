# ROBOT-R17 — Decision quality

R17 separates decision-quality diagnostics from safety validation. The proprietary engine is executed only in a private isolated workspace against deterministic fictional markets. GitHub receives only this public evaluator, tests, documentation and a digest of the private result set.

The public evaluator checks:
- harm rate;
- abstention/conservatism rate;
- new-negative cost;
- missed winners;
- degradation;
- response to increasing synthetic operator intent error.

The main falsification question is whether assisted modes help poor synthetic intent without harming an already-aligned operator. All metrics remain synthetic lab evidence only and cannot be presented as real profitability, customer savings or trading accuracy.
