# ROBOT-R24 — Master Performance Ledger

This block creates the long-lived scorecard requested for the final launch review.

The ledger must always distinguish:
1. technical safety;
2. laboratory/synthetic quality;
3. public read-only evidence;
4. prospective evidence;
5. real broker PnL / real avoided losses / real accuracy.

Only category 5 may be described as real trading performance, and it remains null until independently evidenced.

Current tracked robots:
- Manual
- Hybrid
- Reverse
- UltraFast

The ledger is append-only by block. Later blocks should update the same fields rather than inventing new incompatible scorecards.
